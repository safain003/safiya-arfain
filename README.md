# Safiya Arfain K — Portfolio

A responsive single-page portfolio built from the supplied resume and the supplied health/nutrition illustration.

## Files

- `index.html` — portfolio structure/content
- `styles.css` — responsive styling and olive/leaf/lime visual system
- `script.js` — mobile navigation and scroll-reveal animation
- `assets/health-nutrition-logo.jpg` — supplied visual

## Run locally

Open `index.html` directly in a browser, or use VS Code Live Server.

## Deploy

This is static HTML/CSS/JS, so it can be deployed to GitHub Pages, Netlify, Vercel, or any static hosting service.

## Design

Palette is inspired by the supplied illustration:
- Forest green: #526F3F
- Deep green: #30462A
- Leaf green: #718C4D
- Lime yellow-green: #C7C95B
- Warm cream: #FBFBF7


Dark mode includes explicit text-contrast overrides for headings, body text, labels, pills, links, cards, and secondary text.
